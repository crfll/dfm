# dfm
mitm domain fronting using mitmproxy

## Quick start
```
git clone https://github.com/crfll/dfm
cd dfm
pip install mitmproxy
mitmdump --set confdir=./ -s .\dfm.py  --set connection_strategy=lazy --set http2=false
```

## Setup your browser
mitmproxy runs an http proxy on your localhost on port 8080 thus you need to set your browser's proxy to 127.0.0.1:8080

Firefox: 
go to "about:preferences#general" then scroll to the bottom then click configure proxy then select manual proxy configuration and then set the http proxy

Chrome:
uses system proxy thus you need to set your system proxy to 127.0.0.1:8080 or use an extension like foxyproxy

## Install the CA certificate
1. double click the certificate generated by mitm proxy (should look something like this: mitmproxy-ca-cert.cer)
2. click install certificate
3. choose current user
4. select "place all certificates in the following store" then click browse and then choose "trusted root certification"
5. click next and then finish
6. restart your browser if you get the unsafe connection error
